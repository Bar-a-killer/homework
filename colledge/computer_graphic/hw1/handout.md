## 一、操作方法

### 1. 基本操作

| 操作 | 功能 |
|---|---|
| 右鍵 | 開啟主選單 |
| 左鍵拖曳 | 依目前工具繪圖 |
| `q` / `Q` | 離開程式（輸入文字時無效） |

### 2. 選單結構

```
主選單
├── colors      white / red / green / blue / black
├── type
│   ├── Draw    自由繪圖
│   ├── Line    直線
│   ├── Circle  圓形
│   ├── Polygon ▸ Triangle / Rectangle / Pentagon / Hexagon
│   ├── Text    文字
│   ├── 67      動態 67 圖章
│   └── Eraser  橡皮擦
├── Size        5 ~ 29（線寬、筆刷大小、圓環粗細）
├── file        save / load / clear / quit
├── Fullfilled  On / Off（圓形與多邊形實心／空心）
├── Grid        On / Off（背景格線）
└── Font        8x13 / 9x15 / Times Roman 10, 24 / Helvetica 10, 12, 18
```

### 3. 各工具使用方式

**Draw**：按住左鍵拖曳，筆跡跟著滑鼠移動。

**Line**：按下的位置為起點，放開的位置為終點，拖曳時即時預覽。

**Circle**：按下與放開的兩點為直徑兩端。空心時圓環粗細等於 Size；Fullfilled 為 On 時畫成實心圓。

**Polygon**：先在子選單選擇邊數，再拖曳出一個方框，程式依方框自動算出頂點。Fullfilled 為 On 時畫成實心。

**Text**：點一下設定文字位置，接著用鍵盤輸入。`Backspace` 刪除最後一個字，`Enter` 確認寫入畫布。字型由 Font 選單選擇。

**67**：點一下放置一個「67」圖章，「6」與「7」會持續上下交錯跳動。顏色與大小沿用目前設定。

**Eraser**：用法與 Draw 相同，擦除寬度等於 Size。

### 4. 檔案選單

| 項目 | 功能 |
|---|---|
| save | 儲存目前畫布 |
| load | 還原到上一次 save 的畫布 |
| clear | 清空畫布 |
| quit | 離開程式 |

## 二、作業要求對照

| 要求 | 實作 |
|---|---|
| 3(a) 階層式選單 | 主選單 → 子選單 → Polygon 子選單，共三層 |
| 3(b) 鍵盤／滑鼠／視窗／motion 事件 | `keyboard`、`mouse_func`、`reshape_`、`motion_func` |
| 3(c) 選單改變屬性 | 顏色、線寬、填滿模式、字型 |
| 3(d) 滑鼠控制繪圖 | 拖曳決定直線端點、圓的直徑、多邊形頂點 |
| 進階 (a) 儲存 color buffer | 繪製完成時以 `glReadPixels` 存回主記憶體 |
| 進階 (b) display 時貼回 | `display` 中以 `glDrawPixels` 貼回 |
| 進階 (c) 使用者儲存畫面 | file → save / load |
| 進階 (d) 輸入字串 | Text 工具 |
| 進階 (e) 格線 | Grid 選單 |
| 進階 (f) 其他創意 | 見「三、特殊貢獻」 |

## 三、特殊貢獻

1. **67 動態圖章**：由 timer 驅動，「6」與「7」交錯跳動，可被 save / load 一併保存。
2. **橡皮擦**。
3. **所有工具皆有即時預覽**，包含文字輸入。
4. **圓形筆頭**：粗線自由繪圖時轉角平順無缺口。
5. **多種多邊形**：三角形、矩形、五邊形、六邊形，以同一套三角函數公式計算頂點。
6. **視窗縮放時保留畫布內容**。

## 四、心得

已經四、五年沒有這樣土法煉鋼了，如果哪天失業我會跟著我的圖學作業一起去宜蘭傳統藝術中心表演。
本次作業因時間問題沒有好好的把全預變數好好的分類我很抱歉，程式結構也偏雜亂，程式的順序與後面menu的順序甚至不同。
這次酷酷的67功能使至於需要把所有的繪圖作業程式化，並使用全域變數控制，此一設計在後面的其他細節功能實作上省下了大量的時間。基本的程式架構對開發真的很有幫助。
這次作業從發布當天就開始動工了，但依然沒有把GUI凹出來，只搞了個酷酷的67功能，這個之後可以擴充到其他的動畫或簡單的2D物理模擬顯示。
Grid會持續地顯示在前方，如過有時間餘裕的話會希望把背景跟其他資訊分開讓grid能藏在下面。
67始終於最上層，這個我還沒想到甚麼好的解方。
Cmake在vscode插件上並不是非常友善，所以我決定直接用指令編譯(不用按來按去挺好的)。
